## Título e visão geral do projeto

Este projeto consiste no desenvolvimento de um portfólio pessoal para apresentar minha trajetória acadêmica, meus conhecimentos em tecnologia, meus cursos, minhas atividades complementares e meus projetos.
O site foi desenvolvido com foco na organização das informações, na navegação entre páginas e na apresentação dos meus conhecimentos em desenvolvimento web. O portfólio também serve como registro da minha evolução acadêmica e profissional na área de tecnologia.

## Acesso à aplicação

**Link do portfólio publicado na Vercel:** https://nss-portfolio312.vercel.app/


## 🛠️ Tecnologias e bibliotecas utilizadas

- **HTML5:** estruturação do conteúdo e das páginas do site.
- **CSS3:** estilização, cores, tipografia, layout e apresentação visual.
- **Bootstrap 5.3.8:** framework CSS para auxiliar no desenvolvimento de interfaces e disponibilizar componentes e classes utilitárias.
- **JavaScript:** suporte a funcionalidades interativas por meio dos recursos utilizados no projeto.
- **Git e GitHub:** versionamento do código-fonte e hospedagem do repositório.
- **Vercel:** publicação e disponibilização do portfólio na internet.
